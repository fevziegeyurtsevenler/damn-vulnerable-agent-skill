# Security policy

This repository contains **intentionally vulnerable, defanged teaching artifacts**.
They use `evil.example` hosts and dummy paths and are safe to read and scan. They are
**not** safe to install into a real agent, IDE, or MCP host.

- Do not deploy any scenario into an environment with real credentials or data.
- If you find a way to make a scenario *more* educational (a new class, a better
  defanged example), open a PR.
- To report a problem with the repo itself, use GitHub Security Advisories.
